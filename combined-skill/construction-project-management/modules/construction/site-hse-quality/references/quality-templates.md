## 1. ITP: example for cast-in-situ RC slab

| # | Activity | Spec ref | Acceptance criteria | Frequency | Record | Contractor | Consultant |
|---|---|---|---|---|---|---|---|
| 1 | Material approval (concrete mix, rebar) | 03 30 00 / 03 20 00 | Approved submittal | Once | Approval | R | H |
| 2 | Formwork: line, level, dimensions | 03 10 00 | ±5 mm level, ±10 mm line | Each pour | Checklist | I | W |
| 3 | Reinforcement: size, spacing, cover, laps | 03 20 00 | Per drawings; cover ±5 mm | Each pour | Checklist | I | **H** |
| 4 | Embedded MEP services | MEP specs | Per coordinated drawings | Each pour | Checklist | I | **H** |
| 5 | Pre-pour check / pour permit | — | All above signed off | Each pour | Pour card | I | **H** |
| 6 | Fresh concrete: slump, temperature, cubes | 03 30 00 | Slump per mix design; T ≤ 32 °C (hot weather); 1 set per 50 m³ | Per truck / per 50 m³ | Delivery notes, test log | I | W |
| 7 | Curing | 03 30 00 | ≥ 7 days wet curing / compound | Daily | Log | I | S |
| 8 | Cube results 7 / 28 day | 03 30 00 | ≥ fck per acceptance rules | Per set | Lab reports | R | R |
| 9 | Surface finish and tolerances | 03 35 00 | Flatness per class | Each bay | Survey | I | W |

H = Hold, W = Witness, R = Review, S = Surveillance, I = Inspect

## 2. Inspection request (WIR / IR)

```
WIR no. / Date / Time requested (≥ 24 h notice unless the contract says otherwise)
Discipline / Location (building, level, grid) / Activity / ITP ref & item no.
Drawings (no./rev) / Approved material submittal refs
Contractor's QC inspection done by / date / result: attach checklist
Consultant's inspection: date / inspector
Result: A Approved | B Approved with comments | C Rejected (reinspection required); NCR ref if applicable
Comments / signatures
```

## 3. NCR

```
NCR no. / Date / Raised by (Contractor QC / Consultant / Client) / Discipline / Location
Requirement: spec clause / drawing / standard
Non-conformance: factual description, with photos and measurements
Category: Minor | Major | Critical (structural / safety)
Immediate containment: stop work? quarantine material?
Root cause: method / material / manpower / machine / measurement / design
Proposed disposition: Rework | Repair (method attached) | Use-as-is (designer approval needed) | Reject & replace
Corrective action (fix this) / Preventive action (stop it recurring)
Consultant response: Accepted | Rejected | Comments
Verification and close-out: date, inspector, evidence
Cost/time impact: borne by the Contractor unless due to a design error (then flag it as a potential Variation)
```

## 5. Daily site report

```
Project / Report no. / Date / Day / Contract day no. / Days remaining
Weather: AM / PM, temperature (max/min), rain (hours), wind (hours above lifting limit)
Manpower: table by trade x (own / subcontractor) x (skilled / unskilled); total
Plant & equipment: item / no. / working / idle / breakdown (hours)
Work progress: location / activity (programme ID) / quantity today / cumulative
Materials received: item / quantity / delivery note / inspected (Y/N)
Inspections: WIR nos. and results
Instructions received: ref / from / subject
RFIs / submittals issued today
HSE: man-hours, incidents, near misses, toolbox talks, permits issued
Delays / disruptions: event / cause / time lost / activities affected / notice ref
Visitors
Photos: list with captions
Signatures: Contractor site manager / Consultant resident engineer (countersignature "received, not agreed" if disputed)
```
