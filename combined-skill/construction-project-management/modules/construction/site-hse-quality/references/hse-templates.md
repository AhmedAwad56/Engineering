## 1. 5×5 risk matrix

Risk = Likelihood (1 Rare … 5 Almost certain) × Severity (1 Negligible … 5 Fatal/catastrophic)

| Score | Rating | Action |
|---|---|---|
| 1–4 | Low | Proceed with standard controls |
| 5–9 | Medium | Proceed with specific controls; supervisor to monitor |
| 10–14 | High | Senior approval; additional controls before starting |
| 15–25 | Very high / intolerable | Don't proceed; redesign the task |

## 2. RAMS

```
Project / Contract no. / RAMS ref / Rev / Date
Activity: [e.g. Installation of precast hollow-core slabs, Level 2-5]
Location / Duration / Working hours
Prepared by / Reviewed by (HSE) / Approved by (PM) / Consultant approval status

1. Scope of work
2. References: drawings, specs, ITP, lifting plan, manufacturer's instructions, local regulations
3. Responsibilities: site manager, supervisor, HSE officer, appointed person (lifting), banksman, operatives
4. Resources: manpower by trade and competence certificates; plant with third-party certificates; tools
5. Sequence of work: numbered steps
6. Risk assessment: table (see JSA format), including residual risk
7. Emergency arrangements: first aider, nearest hospital, rescue plan (work at height / confined space)
8. Environmental controls: dust, noise, spills, waste segregation
9. Quality controls: ITP reference and hold points
10. Briefing record: names and signatures of the workforce
```

## 4. Permit-to-work checklist (general)

- [ ] The permit type is correct (hot work / work at height / confined space / excavation / electrical isolation / lifting)
- [ ] RAMS approved and briefed
- [ ] Area inspected; hazards identified; isolations applied (LOTO tags numbered)
- [ ] Gas test results recorded (confined space / hot work): O₂ 19.5–23.5%, LEL < 10%, H₂S, CO
- [ ] Fire watch assigned (hot work, plus 30–60 min after the work ends)
- [ ] Rescue plan and equipment in place
- [ ] Competent persons named; permit issuer and receiver signatures
- [ ] Validity (the shift, normally no more than 12 hours), then handback and close-out signatures

## 6. Incident report and investigation

```
Incident ref / Date & time / Location / Reported by / Classification:
  Near miss | First aid | MTC | RWC | LTI | Fatality | Dangerous occurrence | Environmental | Property damage
Persons involved (name, employer, trade, experience) / Witnesses
Description: what happened (facts only, in sequence)
Immediate actions taken
Evidence: photos, sketches, statements, CCTV, permits, RAMS, training records
Root cause analysis (5 Whys / fishbone): immediate cause -> underlying cause -> root (system) cause
Corrective & preventive actions: action / owner / due date / verified by
Regulatory and client notifications: to whom / when / reference
Lessons learned: to be shared through toolbox talks
```
